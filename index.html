端到端加密聊天室 (E2EE Chat)

Web Crypto API

注重隐私安全的前后端分离实时通讯应用，服务端仅作为数据中继，无法获取任何明文消息内容。

GoReactWebSocketPostgreSQL
  • 使用 Go 语言原生 WebSocket 实现了高并发、低延迟的消息中继服务，保障消息实时送达。
  • 在 React 前端利用 Web Crypto API 生成并交换公私钥，实现消息在浏览器端的端到端加密（E2EE），数据库仅存储加密后的 Payload。
  • 设计并实现了优雅的即时通讯 UI 及断线重连机制，保障弱网环境下的用户体验。
