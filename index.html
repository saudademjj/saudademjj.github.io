04 / PRINCIPLES

工程与产品原则

贯穿所有独立开源项目的默认约束。

01

轻量与本地优先

克制依赖膨胀，优先选择启动快、可离线运行、数据归用户所有的交付形态——无论是原生 Rust 桌面包还是零构建纯前端。

02

隐私与事实边界

在架构层保障隐私（客户端加解密、零多余埋点），对 AI 输出强制事实来源核验与确定性数据库兜底，不靠黑盒碰运气。

03

清晰、可复现的交付

自动化 CI、明确版本发布与直白的技术文档优先于营销包装；开源问题反馈与协作统一通过各仓库 GitHub Issues / PRs 进行。
